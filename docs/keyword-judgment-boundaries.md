# Amazon 关键词判定边界

- Status: verified
- Baseline: V2.1
- Last reviewed: 2026-08-20
- Scope: 已确认的关键词收集、品类清洗、V2.2 词频组件、第三板块分类结构、竞争性判断边界、品类 F1–F3 趋势图输出边界、首轮正常案例规则回写、未完成否词规则的停止门和稳定知识发布边界

本文只定义“如何判定、何时停止、什么不能越界”。业务知识见 `../knowledge/product-keyword-library.md`；逐步执行流程见项目 `.agents/skills/`。

## 1. 全局边界

1. 相关性以完整关键词的中心购买对象为主，不以单个词、搜索量、词频或主观熟悉度替代。
2. 来源可信度与语义相关性分开记录；来源可靠不代表词与当前品类或 SKU 相关。
3. 第二板块只判断一级品类相关性；SKU 事实卡只在第一、第二板块使用，第三板块不判断 SKU 精准适配。
4. 每个候选词在当前清洗版本只有一个去向；不能同时进入 Sheet2、Sheet3 和 Sheet4。
5. 阶段前置事实不足或规则冲突时停止并请求确认；第二板块的单词语义歧义仍按已确认规则进入 Sheet3，并附加人工复核标记，不能脱离三张表悬空。
6. 类目案例只能校准方法，不能把某个案例的具体词直接固化为跨类目词典。

## 2. 收集边界

### 固定来源与顺序

1. 用户业务输入包括产品基础信息、产品基础配置和通常 3–5 个直接竞品 ASIN；首次输入同时在产品事实中记录自有品牌名及别名，没有自有品牌时明确写`无`。站点是工具参数，不是关键词来源。
2. 本轮只使用三类来源：SIF MCP 竞品流量词、Amazon 搜索框联想和卖家精灵 MCP 关键词挖掘；未经新确认不得增加第四类来源。
3. SIF 是第一个实质采集步骤：逐个竞品查询最近 30 天，每个 ASIN 取 V2.1 已确认的 300 条接口上限。调用前先建立本机 Git 忽略的批次目录；每次返回后立即保存完整原始响应、参数、ASIN、站点、抓取时间、数据截止日、返回行数和批次 ID，再做汇总。接口不返回准确起始日时，只记录`最近30天 + 数据截止日`，起始日写`接口未返回`，不得倒推。
4. SIF 流量词先提出一级品类核心大词候选；产品基础信息确认一级品类，基础配置确认目标 SKU 的产品细分品类词。两层词必须分开。
5. Amazon 搜索框联想是第一板块必选来源。当前正式环境固定为 Codex 内置浏览器、Amazon US 未登录、Department=`All`、配送邮编=`10001`；只围绕流量最大的主一级品类核心大词执行固定矩阵。必须记录实际浏览器环境、登录状态、邮编、部门、采集时间和执行次数，不得写成无痕模式。
6. 卖家精灵对去重后的 1–3 个代表种子从第 1 页按每页 20 条连续获取到明确结束。卖点、功能、材质、颜色、尺寸或配置组合词不能作为起始种子；代表种子不需要凑满三个。
7. 用户已确认当前电脑的 SIF MCP 和卖家精灵 MCP 已连接，不设置例行连通性复验；实际执行中出现明确不可用或结构冲突时才按异常停止。

### 可以进入原始候选池

- 来自已授权来源且能够保留来源、查询词、时间口径和原始文本的结果。
- Amazon 搜索框中以主一级品类核心大词产生的非问题式联想。
- 由去重后的 1–3 个扩词种子产生、并能追溯到种子和来源的结果。

### 不能宣称完成

- 接口报错、分页不完整、来源字段缺失或返回零结果但原因未查明。
- Amazon 联想无法被内置浏览器识别、操作或完成固定矩阵。此时必须记`not_executed`，不能记为零结果、已完成，也不能用搜索结果页、网页搜索、外部浏览器或 API 替代。
- 只保存整理后的词，没有原始来源明细。
- 把多个渠道简单相加后声称获得“全量关键词”。
- SIF 取满 300 条或卖家精灵分页结束只能称为“接口范围内已完整”，不能称为 Amazon 全量。

### 必须停止或升级人工

- 来源未获授权，或包含账号、Cookie、Token、客户/员工个人信息。
- 产品一级品类无法确认，导致类目锚点无法建立。
- 候选核心词既可能是一级品类，也可能是 SKU 细分类型，且现有证据不能区分。
- 内置浏览器虽能打开 Amazon 页面但不能识别或操作页面。当前把它保留为待解决技术项，不绕过，也不因此把正常案例改称边界案例；本批在联想补齐前保持未完成。

### 分页、重复和字段来源

- 卖家精灵首屏声明总数发生漂移时，若声明页数稳定、页码连续、没有缺页/整页重复/循环且存在明确最后页，可继续到末页并把漂移写入异常日志；行数真值使用实际返回行数。页数变化、缺页、整页重复、循环或无法确认最后页时阻断。
- 分页边界重复关键词必须在原始页表和来源明细中全部保留；`08_原始关键词总表`按机械键只保留一个关键词。相同来源的重复记录指标不一致时，首个出现值只作为展示值，标记同源冲突，并保留全部原始值。
- 来源完成与逐行指标完整是两个状态。缺失 CPC、SPR、商品数量或集中度时保留空值，不填 0、不估算、不按精确词补拉。清洗可以在规范 ABA 或搜索量可用时继续；F1–F4 竞争行缺 SPR 或商品数量时标记`第一板块数据缺失/人工复核`。
- 规范 ABA 和搜索量优先使用卖家精灵；仅存在于 SIF 的词才回退 SIF。必须保留各来源原值、周期、规范字段来源和回退标记，不平均、不静默覆盖。SPR 和商品数量只取卖家精灵原值；SIF-only 词保持空值。

## 3. 类目锚点与细分品类词边界

### 一级品类核心大词

应当能够稳定回答“用户要买的基本商品是什么”，并覆盖同一品类下多个结构或配置。它是第二板块的类目边界，不是对目标 SKU 的完整描述。

### 产品细分品类词

应当仍属于同一一级品类，并描述目标 SKU 实际的细分形态、结构或市场类型；必须有产品基础信息或配置依据，不确定时标记`待核实`。它不是普通颜色、尺寸、单项功能、场景、人群或仅词形变化。其他同品类子类型仍可进入 Sheet2，但不能冒充目标产品的细分品类词。

### 冲突处理

当一个词既像类目锚点又像细分词时，分别记录其市场覆盖范围和目标 SKU 匹配度。证据不足时保留两种候选解释，交主任务确认，不能为推进流程而任选其一。

## 4. 第二板块三去向边界

### 流量入口

当前已确认的待清洗流量选区采用 OR 逻辑，满足任一入口即可继续语义判断：

- 存在有效 ABA 排名，且排名小于或等于 1,000,000。
- 月搜索量大于 100。

ABA 排名大于 1,000,000 但月搜索量大于 100 的词仍需进入语义判断；月搜索量等于 100 不满足搜索量入口，但仍可通过 ABA 入口。两个入口均未满足的词不从原始表删除，进入 Sheet3，且不参与本轮主词频统计。

流量门槛只决定本轮是否继续语义判断，不证明相关性。来源指标缺失或无效必须单独记录。

通过流量入口后，依次执行六层判断：

1. 语义标准化：只清理形式噪声，原词不覆盖。
2. 商品完整性：是否能独立表达完整商品。
3. 中心购买对象：商品头部、用途中心和最终主要交付物是什么。
4. 关系性质：同品类、属性/配置、直接替代、配件/互补、共享场景或无关。
5. 单一或多商品：是否为套装、组合或共同购买。
6. 判断充分性：能否仅凭关键词和类目锚点得出结论，是否依赖来源背景猜测。

正式路由顺序：

1. 先识别品牌、授权/IP、Gift、流量缺失和明显非商品表达。用户声明的自有品牌按完整商品对象继续判断；其他品牌、品牌简称、系列、型号和未声明授权的 IP/角色词进入 Sheet3。Gift 意图进入 Sheet3。
2. 中心购买对象仍是目标一级品类完整商品时进入 Sheet2。
3. 中心对象是不同完整品类且满足全部直接替代条件时进入 Sheet4。
4. 其余进入 Sheet3；无法可靠确定时以`泛词/语义残缺`进入 Sheet3，并附加人工复核标记。

中心购买对象按语义上的商品头部、用途中心和最终主要交付物判断，不固定读取最左词、最右词或核心词出现位置。常见结构的已确认处理如下：

- `一级品类商品 + 属性/功能/人群/场景`：商品中心未离开一级品类时进入 Sheet2；SKU 是否具备不影响第二板块保留，也不在第三板块读取事实卡补判。
- `一级品类商品 with/without/no 配置`：主要交付物仍是本体时进入 Sheet2。
- `配件/互补品 for 一级品类商品`或`一级品类商品 + 配件头部`：主要交付物是配件时进入 Sheet3。
- `相邻完整商品 + 一级品类词根`：共同词根不决定去向，先判断是否满足全部直接替代条件。
- `商品 A and/with 商品 B set/combo`：明确共同购买多个主要商品时进入 Sheet3。
- 无意义符号、不可见字符或异常标点先标准化再判断，原始表达必须保留。
- 英文字母拼写错误不自动摘除：如果原词仍能可靠表达目标一级品类完整商品，保留原词进入 Sheet2并加`错字错词`标签；不增加纠正词或建议纠正字段。`错字错词`只指英文字母拼写错误，不等于同义词、词序、缩写、有效变体或其他语言。
- 可可靠识别的其他语言目标一级品类完整商品进入 Sheet2并加`其他语言`标签；其他语言的相邻完整替代商品可进入 Sheet4。只有宽泛、残缺、无法识别或未形成完整商品对象的其他语言表达才进入 Sheet3。
- 已在当前类目验证为同一完整商品对象的同义表达、词序和有效词形变体进入 Sheet2；该等价映射只作用于当前类目版本，不固化为跨类目词典。缩写不是拼写错误。

### Sheet2：清洗后品类相关关键词库

进入条件是“同一一级品类”，不是“当前 SKU 精准匹配”。以下情况本身不能作为第二板块删除理由：

- 目标 SKU 没有该配置、材质、颜色、尺寸或结构。
- 关键词描述同品类的另一细分类型。
- 关键词流量低或暂时没有广告转化证据。
- 目标完整商品的英语拼写错误、可识别其他语言表达、有效同义表达、词序或词形变体；保留原词并使用相应标签。
- 用户已声明的自有品牌与目标完整商品组合词；加`自有品牌词`标签。自有品牌的相邻完整替代商品仍按 Sheet4 条件判断。

### Sheet4：二类词词库

进入条件是“不同品类，但可直接替代并完成相同核心购买任务”。需要同时满足：

1. 已通过当前流量入口。
2. 关键词能够独立、明确表达一个完整商品，并且不是一级品类自身或正常修饰表达。
3. 该商品与核心品类具有相同或高度一致的主要购买目的，不只是次要功能重叠。
4. 核心品类商品无需增加另一个主要商品、无需显著改变形态，即可直接完成该词的主要任务。
5. 两者通常进入同一次购买比较或替代选择；同场景、结构相似、局部功能相同或可能兼用均不足以成立。
6. 替代关系能够由关键词本身和类目锚点支持，不依靠来源背景或主观猜测。
7. 该词曾由直接竞品 SIF 或卖家精灵结果发现；来源只负责发现候选，不能单独证明替代关系。
8. 不含品牌、Gift、配件、耗材、多商品组合、泛场景或语义残缺表达。

某一案例没有可靠直接替代词时，Sheet4 为零是有效结果。

二类关系以当前核心品类为参照，具有方向性和条件性。某个词在 A 品类中进入 Sheet4，不代表它在 B 品类中仍是二类词；必须分别回答“当前核心品类能否直接完成该搜索词的主要任务”和“买家是否会在同一次购买中比较两者”。

### Sheet3：其他摘除关键词库

典型原因包括：

- 除用户声明的自有品牌外，任何可识别品牌、品牌简称、系列、型号或其拼写变体；整词摘除，不删除品牌后生成新词。未声明授权的第三方 IP、角色或联名词同样摘除。
- 明确 Gift、送礼、赠品或 Gift Ideas 意图。
- 配件、零件、耗材、维护或服务。
- 残缺、过泛或存在无法消除的多义性。
- 只表达场景、人群、活动或需求，但没有完整商品对象。
- `A and B`、`A with B set`、`combo`等多个主要商品共同购买表达。
- 完整但只与目标品类共享场景、结构或局部功能，不能直接替代的其他商品。
- 中心购买对象与目标品类完全无关。
- 规范 ABA 和规范搜索量同时缺失或无效，原因写`缺流量数据`。

`一级品类商品 with/without/no 配置`且主要交付物仍是本体时进入 Sheet2；`配件 for 一级品类商品`或`一级品类商品 + 配件头部`且主要交付物是配件时进入 Sheet3。目标完整商品的同义表达进入 Sheet2；能够直接替代但不属于目标一级品类标准商品形态的相邻完整商品进入 Sheet4；泛属性、场景或对象残缺表达进入 Sheet3。非英语关键词使用同一中心购买对象门槛，不能因语言不同自动保留或删除。原因必须基于完整词表达，不得仅凭命中黑名单单词自动摘除。

自动化目标是用户只提供初始产品事实、自有品牌、站点和竞品，系统完成分流并返回最终工作簿。正式运行中不逐词中断询问；当前规则无法可靠识别时保守进入 Sheet3并写明具体原因。每次真实验证后的边界修正必须重跑当前案例，并输出旧去向到新去向的差异表；未重跑前不得把旧工作簿称为新规则结果。

## 5. 第三板块与最终工作簿启用边界

第三板块包括关键词分类、F1–F4 竞争性分析、Sheet3 否词库设计、Sheet4 二类词流量分类和品类 F1–F3 历年月度搜索量折线图，之后装配最终工作簿。关键词分类已建立 draft Skill，执行确认的 F1–F5、基础多标签、F5唯一主标签组内LT、Sheet4流量分类和 Sheet3候选结构；规范 ABA 缺失或不可比时不伪造流量层，否词最终方式仍须人工。竞争性判断边界和趋势图结构已同步到 draft Skill，但尚无 P1；趋势图不生成趋势标签或自动结论。

### 5.1 启动前置

必须同时锁定：

- 第二板块工作簿版本、`Keyword_ID` 和 Sheet2/3/4 原始行数。
- 第一板块 `06_卖家精灵原始数据`的批次版本、站点、采集周期和原始字段。
- 类目锚点卡、站点和数据周期；SKU 事实卡不得传入第三板块。
- 词频分支与分类分支锁定同一第二板块版本；分类启动不等待`Sheet5_词频统计`完成。最终装配前必须锁定词频组件版本、输入关键词数和数量闭环状态；词频只作为过程 Sheet 与血缘记录，不作为第三板块判断字段。

第三板块不能覆盖第二板块原表。分类、竞争性和趋势性使用约定的独立派生过程 Sheet；详细竞争指标不铺入最终关键词决策总表，只回写竞争记录引用与综合结论；趋势集中写入一个品类级 Sheet。缺少稳定 `Keyword_ID` 或输入版本时停止，不能用关键词文本近似连接，也不能把 Sheet2 解释为 SKU 精准词库。

### 5.2 已确认的 Sheet2 分类结构

Sheet2 的 ABA 流量层采用互斥区间：

| 代码 | ABA 排名 | 分类名称 |
|---|---:|---|
| F1 | 1–10,000 | 一级核心大词 |
| F2 | 10,001–20,000 | 二级流量词 |
| F3 | 20,001–50,000 | 中等流量词 |
| F4 | 50,001–100,000 | 中长尾词 |
| F5 | 大于 100,000 | 长尾词 |

F2“二级流量词”不能与 Sheet4“二类词”混用。第二板块已按 ABA 或搜索量通过流量门，因此第三板块不把“ABA缺失”单独当作异常终止条件；存在有效 ABA 时按上表分层，无 ABA 时保留规范搜索量与来源并标记`ABA未提供`，不得伪造排名。

F5 必须先保留全部语义多标签，再为每词选择一个`长尾主分组标签`，每个关键词只出现一次。主标签优先级固定为：`承重/容量/功率/数量/参数 > 尺寸/规格 > 颜色/图案/风格 > 人群 > 功能/卖点 > 材质 > 细分类型/结构 > 场景/用途 > 其他语言 > 错字错词 > 品类/产品`。每个主标签内部按 ABA 升序排列；该标签组超过 20 个词时再拆 `LT-1`、`LT-2`……，每个子组最多 20 个。流量排序优先于标签内其他选择条件。

词性/词义采用多标签，跨类目起始维度包括品类/产品、细分类型/结构、功能/卖点、颜色/图案/风格、材质、尺寸/规格、承重/容量/功率/数量/参数、人群、场景/用途、兼容对象/型号、需求/痛点、其他语言、错字错词、自有品牌词和其他/未知。类目专属等价表达可按本类目验证结果追加，但历史案例中的具体词不得直接成为跨类目固定词典。多标签本身不冲突；只有 F5 需要按上述优先级选一个主分组标签。

语义标签只描述关键词自身的词性和词义，不读取 SKU 事实卡，不记录 SKU 的`匹配`、`冲突/不匹配`、`事实不足`或其他适配状态，也不能直接解释为“可投放”或“不可投放”。

Sheet2 核心关键词分类过程表保持每个 `Keyword_ID` 一行。重复主键、丢失主键、原始行数变化或无法追溯数据周期时停止。

### 5.3 Sheet4 与 Sheet3 边界

Sheet4 二类词按与 Sheet2 相同的 F1–F5 和 LT 分组规则生成独立二类词流量表，不与 Sheet2 合并。二类商品类型、中心购买对象和直接替代理由必须保留；二类词身份继续由第二板块规则拥有，第三板块不能因为流量层变化而改写其二类词身份。二类词不进入竞争性或趋势性分析。

Sheet3 的目标划分为`精准否定`、`词组否定`、`不否定`和`需人工确认`。当前只确认输出结构，未确认可直接投放的判断边界。尤其在以下规则完成前，Sheet3 只能称为否词候选库：

- 词组否定是否会误伤 Sheet2 或 Sheet4 中仍需保留的完整表达。
- 品牌、配件、Gift、泛词、场景词和完全无关词分别适用何种否定方式。
- 广告组级、活动级和匹配方式之间的发布范围。

任何可能扩大误伤范围的词组否定必须进入人工确认，不能为了提前生成广告结构而自动通过。

### 5.4 竞争性与趋势性边界

竞争性只处理 Sheet2 的 F1–F4；趋势图只处理 Sheet2 的 F1–F3。F5、Sheet3 和 Sheet4 均不进入两者，F4 可进入竞争性但不进入趋势图。竞争性明细独立形成`第三板块_关键词竞争性分析`Sheet；趋势统一形成一个品类趋势 Sheet。两者都不写入最终关键词决策总表。

#### 5.4.1 竞争数据来源和接口边界

正式判断输入只使用：

| 字段 | 正式来源 | 用途 |
|---|---|---|
| `SIF_CPC` | `market_screen_keyword_opportunities` | 广告成本维度 |
| `SIF_Top3点击份额` | `market_screen_keyword_opportunities`，必要时以 `market_get_keyword_competition`补充历史解释 | 头部流量入口锁定 |
| `SIF_Top3转化份额` | `market_screen_keyword_opportunities`，必要时以 `market_get_keyword_competition`补充历史解释 | 头部购买漏斗锁定 |
| `SIF_市场CVR` | `market_screen_keyword_opportunities` | 市场转化环境修正项 |
| `卖家精灵_SPR` | 第一板块 `06_卖家精灵原始数据`锁定批次 | 排名门槛维度 |
| `卖家精灵_商品数量` | 第一板块 `06_卖家精灵原始数据`锁定批次 | 供给拥挤维度 |
| `SIF_入场信号` | `market_screen_keyword_opportunities` | 与项目综合等级做一致性复核，不重复计分 |

SIF 只允许调用 `market_screen_keyword_opportunities` 和 `market_get_keyword_competition`；`market_get_keyword_root_competitors` 不调用。机会筛选结果必须对完整关键词做精确匹配，不能用词根、近似词或返回排序代替。关键词竞争格局在当前第三板块不传目标 ASIN，只可补充集中度等级、点击与转化走势分化、Top3 之外购买空间、头部流量渠道结构和可进入性解读；目标 ASIN位置、广告重点和行动建议不进入当前输出。

卖家精灵 CPC、点击集中度、转化集中度等原值可保留在竞争 Sheet 的过程证据区，但不参与正式综合等级。竞争性步骤不得重新调用卖家精灵关键词挖掘、按精确词补拉或局部刷新。SPR 或商品数量缺失时标记`第一板块数据缺失`；需要刷新时重跑一个版本化的第一板块采集批次。

#### 5.4.2 独立竞争 Sheet 最低字段

`第三板块_关键词竞争性分析`保持一词一行，至少包含：

- 身份与追踪：`Competition_Record_ID`、`Keyword_ID`、关键词、中文翻译、流量层、站点、分析周期、规则版本、SIF机会筛选周期、SIF竞争格局周期、卖家精灵采集周期。
- 正式输入：SIF CPC、SIF Top3 点击份额、SIF Top3 转化份额、SIF 市场 CVR、SIF 入场信号、卖家精灵 SPR、卖家精灵商品数量。
- 辅助证据：SIF 集中度等级、Top1/2/3 点击 ASIN、头部 ASIN自然/SP/品牌/视频流量占比、集中度历史、可进入性解读，以及卖家精灵原始 CPC/点击集中度/转化集中度（若上游存在）。
- 派生结果：机会筛选精确匹配状态、比较池范围、比较池有效样本数、分位数回退层级、点击转化差、头部锁定度、CPC 等级、SPR 等级、商品数量等级、CVR 环境、综合竞争等级、竞争判断摘要、入场信号一致性、数据完整性、置信度和人工复核状态。

#### 5.4.3 Top3 固定绝对阈值

Top3 点击份额和 Top3 转化份额分别按下列阈值分层：

| 数值 | 等级 |
|---:|---|
| `<30%` | 低 |
| `30%–<50%` | 中 |
| `50%–<70%` | 高 |
| `>=70%` | 极高 |

头部锁定度按以下顺序判断：

1. 两者均为极高，或一项极高且另一项高：`极高`。
2. 任一项为高、两者均为高，或一项极高而另一项为低/中：`高`；最后一种同时标记`结构分化`。
3. 未达到高且至少一项为中：`中`。
4. 两者均为低：`低`。

点击与转化的差值用于解释结构：

- `Top3转化份额 - Top3点击份额 >= 15`个百分点：`头部转化效率壁垒`。
- `Top3点击份额 - Top3转化份额 >= 15`个百分点：`点击流量被锁但购买相对分散`。
- 绝对差值小于 15 个百分点：`结构基本一致`。

#### 5.4.4 相对分位数和样本回退

CPC、SPR、商品数量和市场 CVR 的比较池必须是同站点、同品类、同数据周期、同流量层。样本按下列顺序回退：

1. 当前流量层有至少 10 个有效关键词：仅在该层计算。
2. 少于 10 个：合并 F1+F2 或 F3+F4。
3. 合并后仍少于 10 个：使用全部 F1–F4。
4. 全部 F1–F4 仍少于 10 个：CPC、SPR、商品数量和市场 CVR不输出相对高/中/低，综合竞争等级也不输出；只保留原始值、可独立判断的 Top3 绝对层、入场信号和辅助证据，统一标记`数据不足/人工复核`。

CPC、SPR 和商品数量：`<=P33`为低，`>P33 且 <P67`为中，`>=P67`为高；数值越高，竞争门槛越高。市场 CVR：`<=P33`为弱，`>P33 且 <P67`为中，`>=P67`为良好。市场 CVR 不是低竞争证据，必须与 Top3 转化份额联读：

- CVR良好 + Top3转化低：市场转化良好且购买分散，利于进入。
- CVR良好 + Top3转化高/极高：市场可转化，但订单被头部锁定。
- CVR弱 + Top3转化低：可能是需求或承接弱，不能直接称低竞争。
- CVR弱 + Top3转化高/极高：整体转化弱且有限订单被头部锁定。

#### 5.4.5 综合竞争等级

综合等级按`极高 → 高 → 中 → 低`的顺序命中首个规则。四个竞争维度是头部锁定度、SPR、CPC 和商品数量；市场 CVR只作最多一级的修正。

`极高`，满足任一：

- Top3 点击与转化均为极高。
- 头部锁定度为高，且 SPR 或 CPC 为高。
- SPR 与 CPC 均为高，且商品数量为高或市场 CVR为弱。

`高`，在未命中极高时满足任一：

- 头部锁定度为高。
- SPR、CPC、商品数量中至少两项为高。
- 其中一项为高，另外两项均至少为中。
- 原始判断为中，市场 CVR为弱，且头部锁定度、SPR、CPC 至少一项不低于中。

`中`，在未命中极高/高时满足任一：

- 任一竞争维度为高。
- 至少两个竞争维度为中。
- 只有一个竞争维度为中，但市场 CVR为弱。

`低`必须同时满足：头部锁定度低、SPR低、CPC低、商品数量低或仅商品数量中、市场 CVR为中/良好，且不存在来源冲突或关键缺失。

市场 CVR良好最多降低一级，CVR弱最多提高一级；CVR良好不得把高/极高头部锁定降为中/低，也不得在 SPR 与 CPC 均高时把综合等级降为中。

#### 5.4.6 SIF 入场信号一致性

SIF 入场信号不重复计入综合等级，只作交叉验证。保留接口原始值和解释，不在知识库预设一套未经接口文档确认的固定标签词典；仅当返回值或其解释能够明确对应低/中/高竞争方向时才归一比较，无法明确归一时标记`无法验证`。

- 方向一致：`一致`。
- 相差一级：`轻微差异`。
- 相差两级或以上：`冲突/人工复核`。
- 无法归一或数据不足：`无法验证`。

SIF 显示可切入但项目头部锁定极高时，不自动降级，先检查历史与数据周期；SIF 显示竞争激烈但项目等级低时，复核关键词精确匹配、CPC、CVR 和 Top3 口径。

#### 5.4.7 完整性、周期与正式输出门

满足以下全部条件才可输出正式综合等级：Top3 点击与转化均完整；CPC、SPR、商品数量至少两项可用；SIF 与卖家精灵来源周期可追溯；机会筛选已精确匹配完整关键词；分位数比较池回退后仍有至少 10 个有效关键词。

以下情况可输出等级但降低置信度并标记`部分完整`：CPC、SPR、商品数量仅缺一项；市场 CVR缺失；两个 SIF 接口周期不同但方向一致。

以下情况不输出正式等级，统一标记`数据不足/人工复核`：Top3 点击或转化缺失；CPC、SPR、商品数量缺失两项或以上；机会筛选未精确匹配完整关键词；回退至全部 F1–F4 后有效样本仍少于 10；不同周期呈相反方向；SIF 入场信号与项目等级相差两级或以上且未解决；关键词不属于 F1–F4。`market_get_keyword_competition`只提供辅助格局和可进入性解释，不能替代机会筛选的精确完整词正式值。两个 SIF 接口字段不同不得平均或互相覆盖。

竞争性分析不得输出`直接打`、`测试`、`暂缓`、广告资格或广告结构结论。

趋势性输出只观察关键词搜索量，不分析购买量、购买率、需求质量或目标 ASIN 自身排名/流量。正式来源固定为卖家精灵 `aba_research_trend` 返回的精确词历史月度搜索量；不调用 SIF 趋势接口，也不使用西柚 MCP。卖家精灵趋势调用是第三板块获准的历史趋势查询，不得借此重跑关键词挖掘或补拉竞争字段。

每个品类只建立一个趋势性分析 Sheet，只包含 Sheet2 F1–F3 的历年月度搜索量数据矩阵和一张折线图。数据矩阵第一列为`YYYY-MM`，后续每列为一个关键词；横轴为年-月，纵轴为月度搜索量，每个关键词恰好一条折线，图例为关键词。还必须记录品类、站点、正式数据来源、最早月份、最新完整月份、F1–F3 关键词数量、数据完整性和规则版本。

整张正式折线图只能使用卖家精灵月度搜索量。每条返回记录的月份字段必须非空且可解析为`YYYY-MM`；月份为空的响应无效，应调整获准参数重新查询，不能自行生成月份。卖家精灵接口不可用或没有可用完整月时标记`not executed`，不生成替代图，不回退 SIF 或其他平台。当前未结束月份不进入；缺失月份留空并记录缺失，不填 0、不插值、不前值延续，也不用其他来源补值。

本阶段不计算或输出近三月变化、同比、ABA 走势、峰值月、季节性、精确词/长尾结构、品类汇总搜索量线或综合趋势标签。不为每个关键词单独创建 Sheet，不把 F4、F5、Sheet3 或 Sheet4 混入趋势图，不把趋势图解读为广告资格或投放结论。

### 5.5 最终工作簿与后置阶段

最终工作簿的第一张`Sheet1_最终关键词决策总表`只汇总 Sheet2 核心关键词的身份、翻译、来源、流量、分类和竞争性证据。Sheet3 否词库关键词和 Sheet4 二类词不得进入，趋势也不作为行字段写入。广告资格必须后置到该总表之后，不得在分类、竞争难度或趋势标签阶段提前生成。

Sheet1 至少保留：`Keyword_ID`、关键词、中文翻译、标准化关键词、站点、来源渠道、采集批次、数据周期、ABA 排名、搜索量、SPR、流量层代码、流量层名称、LT 分组、词性/词义多标签、`Competition_Record_ID`、综合竞争等级、竞争判断摘要、竞争数据完整性、人工复核状态和规则版本。详细竞争指标只存在于独立竞争性分析 Sheet。F5 行的 `Competition_Record_ID` 为空，综合竞争等级写`不适用（F5）`、竞争数据完整性写`范围外`，不能误报为数据缺失；Sheet1 的人工复核状态汇总分类与竞争复核结果，不能用竞争状态覆盖已有分类复核状态。

最终工作簿必须保留第一、第二、第三板块实际生成的全部过程 Sheet。`Sheet5_词频统计`、Sheet4 二类词流量分类、Sheet3 否词库设计和品类 F1–F3 历年月度搜索量折线图分别独立成 Sheet；最低清单不是删除其他过程 Sheet 的许可。缺少任何应有过程 Sheet、主键映射或行数闭环时不得交付。CSV 来源先导入临时空工作簿再写入目标工作簿；日期必须显示为可读日期而非序列号；ID、来源、周期和说明列设置可读列宽与换行；每张 Sheet 都要渲染复核，含图表 Sheet 必须按固定图表区域预览并检查关键词数、月份数和图表序列数闭合。

用户后续提供的广告活动名称、广告目的和广告关键词通用模板，以及品类通用词库的生成规则，均为待定后置工作。品类通用词库只确认未来输出一张 Sheet、所有分类在同一 Sheet、每个分类下只保留关键词；具体布局和选词规则未确认，当前不得生成固定格式或 Skill。

## 6. 词频分析边界

本节采用已迁入的 V2.2 词频组件业务规则。V2.2 只标识词频组件，不改变 V2.1 项目清洗基线。

### 6.1 输入边界

- 只读取已完成第二板块清洗并通过`Sheet2 + Sheet3 + Sheet4 = 原始行数`闭环的工作簿。
- 只读取 Sheet2 唯一可识别的完整关键词列；表头、空行、Sheet3、Sheet4、流量入口失败词、原始未清洗关键词和额外词表不参加。
- 每个非空 Sheet2 数据行按一次完整关键词出现处理。
- 原工作簿和全部原 Sheet 必须保持不变；结果写入副本。

若 Sheet2 缺失、关键词列无法唯一识别、工作簿损坏或发现无法解释的重复完整关键词，停止并回传，不静默猜列或去重。

### 6.2 机械分词边界

- 对统计副本执行 Unicode NFKC 兼容规范化和英文小写化，不覆盖 Sheet2 原文。
- 空白、标点和连字符作为分隔符。
- 保留字母、数字、停用词、介词和可识别非英语词面。
- 不合并单复数、同义词、拼写变体、词干、词序或跨语言表达。
- 不根据品牌、搜索量、SKU 事实或模型建议再次删词或改词。

### 6.3 计数与排序边界

- 单词词频：每个机械拆分后的词面每出现一次计 1 次；同一完整关键词内重复出现时按实际次数累计。
- 双词词频：只统计同一完整关键词中相邻并保持原顺序的两个词面；不跨关键词、不跳词、不交换词序，`t1 t2`与`t2 t1`是不同双词。
- 第一排序键为重复出现次数降序；次数相同时按规范化词面字符顺序升序。
- 保留所有唯一单词和双词，包括出现 1 次的词面。
- “词频分级”只表示上述排序，不建立高频、中频、低频区间，不加权、不打分。

### 6.4 输出边界

- 在工作簿副本最后新增一个词频 Sheet，当前四张清洗结果表之后固定命名为 `Sheet5_词频统计`。
- 同一 Sheet 同时包含单词词频表和双词词频表；每张表至少包含排名、词面和重复出现次数。
- 同时记录来源 Sheet、输入关键词数、分词与不归并说明、单词总次数、双词总次数、唯一单词数和唯一双词数。
- 已存在同名结果 Sheet 时停止，不静默覆盖或追加第二份同名结果。

### 6.5 验收边界

结果只有同时满足以下条件才可交付：

1. 输入关键词数等于 Sheet2 非空关键词数据行数。
2. 单词频次合计等于全部生成 token 数。
3. 双词频次合计等于每行`max(token 数 - 1, 0)`的总和。
4. 每行至少有一个 token 时，双词频次合计也等于`单词总次数 - 输入关键词数`。
5. 输出数据行数分别等于唯一单词数和唯一双词数。
6. 次数降序和同次数字符顺序稳定。
7. 原工作表未变化，词频 Sheet 位于最后。
8. 公式错误扫描和全部工作表的渲染目视复核无实质问题。

任一数量不闭合、公式检查失败、渲染失败或原 Sheet 被改变时，停止交付，保留源文件并报告准确差异。

### 6.6 非推断与阶段边界

重复次数只描述本批 Sheet2 文本。不得把它解释成搜索量、ABA、流量、点击、转化、竞争性、趋势、Amazon 算法权重、完整关键词相关性或目标 SKU 精准度。词频步骤不调用 SIF、Amazon 搜索框、卖家精灵、广告报告或外部业务系统，也不直接撰写 Listing。

词频与关键词分类在清洗闭环后并行；分类不等待词频结果。最终装配只锁定词频版本用于血缘和过程 Sheet 保留，不得用词频结果影响 F1–F5、词性/词义标签、竞争等级、趋势图、否词方式或广告资格。

### 6.7 Skill 状态边界

- `amazon-keyword-word-frequency` 当前为 `draft`，`keyword.library.word-frequency`为`planned`。
- 完成两个正常案例和一个边界/异常案例的真实执行记录前，不得标记为 `verified`。
- 建立 Skill 前的本地试算不能反向充当 P1 evidence；业务规则已确认不等于能力已验证。

## 7. 发布与版本边界

### 可以进入稳定知识

- 用户明确确认的业务决策。
- 有可追溯来源、适用范围和复核日期的稳定结论。
- 经过人工复核且不包含敏感信息的脱敏证据摘要。

### 只能保留为候选或本地证据

- 外部研究草案、一次性推演和未确认建议。
- 原始聊天、原始 XLSX、截图、检查日志和临时脚本。
- 含联系信息、账号信息、内部网址或源电脑路径的材料。

### Skill 状态边界

- P0 结构合格只表示 Skill 包可审查。
- 新拆分 Skill 必须重新完成两个正常案例和一个边界/异常案例的真实运行，才能标为 `verified`。
- 历史案例发生在 Skill 拆分之前，只能作为方法来源，不反向补写为 P1 evidence。
- 词频组件已形成完整输入、步骤、判断、输出、异常和验收合同并建立 draft Skill，但尚无 P1；关键词分类已有 draft Skill，未确认边界只能作为人工停止门，不能伪装为自动判断。
- 用户已明确授权并完成竞争与趋势两个单一职责 draft Skill 的结构拆分；竞争性来源、字段和判断边界、F1–F3 趋势图结构及卖家精灵月搜索量正式来源未改变。两个能力仍为`planned`，没有真实 P1 案例时不得宣传为已验证。趋势图不生成综合趋势标签；卖家精灵趋势数据不可用时不生成替代图。独立质量验证 Skill 只复核既有合同与证据，不修改业务判断或替代各专责完成门。

## 8. 人工升级格式

无法安全判定时返回：

- 原始词或对象。
- 当前候选去向及各自依据。
- 缺少的产品事实或来源证据。
- 若误判可能造成的下游影响。
- 需要主任务或用户确认的单一问题。
