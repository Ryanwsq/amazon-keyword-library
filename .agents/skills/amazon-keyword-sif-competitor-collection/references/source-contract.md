# SIF competitor source contract

## Input lock

- `Run_ID`、站点、获准竞品清单和本机忽略输出目录必须锁定。
- 每个竞品单独查询；父体无数据时只记录问题并由主任务决定是否补充获准子体。
- 查询口径固定最近30天，请求已确认的每 ASIN 300条适配器上限。

## Persisted response

每次调用至少保存：来源记录 ID、批次、竞品 ASIN、站点、全部请求参数、查询窗口、接口返回日期字段、数据截止日、抓取时间、返回行数、原始响应指针和接口完整返回。接口不返回准确起始日时写`接口未返回`。当前接口没有`returnFields`，不能宣称接口侧已缩减字段。

## Minimal workbook

七列明细固定为：`竞品ASIN`、`SIF返回序号`、`英文关键词`、`ABA排名`、`搜索量`、`Top3点击份额`、`Top3转化份额`。每个竞品返回记录均保留一行，不按相关性删除。核心词候选摘要可按机械键计算竞品覆盖数、最佳/中位返回序号和字段冲突，但不得确认最终锚点。

## Handoff

回传主任务：工作簿、Run相对路径、文件哈希、竞品清单与状态、逐竞品返回行数、七列明细行数、核心词候选数、字段缺失/冲突、原始响应清单指针、异常和完成状态。原始业务响应正文只保留在 `.local/runs/<Run_ID>/keyword-sif-collector/`，不进入主任务消息。

## Gate

每个成功调用均有完整响应、参数、时间、周期、行数和本机指针；七列工作簿与原始记录数量可回查；失败竞品有准确原因。任一响应未保存、站点/父子体不明、接口结构冲突或授权不足时回传`blocked/incomplete`，但不得抹去其他竞品已取得结果。
