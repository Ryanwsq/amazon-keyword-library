# SIF competitor source contract

## Input lock

- `Run_ID`、站点、获准竞品清单和本机忽略输出目录必须锁定。
- 每个竞品单独查询；父体无数据时只记录问题并由主任务决定是否补充获准子体。
- 查询口径固定最近30天，请求已确认的每 ASIN 300条适配器上限。

## Persisted response

每次调用至少保存：来源记录 ID、批次、竞品 ASIN、站点、全部请求参数、查询窗口、接口返回日期字段、数据截止日、抓取时间、返回行数、原始响应指针和全部返回字段。接口不返回准确起始日时写`接口未返回`。

## Handoff

回传主任务：竞品清单与状态、逐竞品返回行数、原始响应清单、来源记录清单、可用流量字段、核心大词候选证据、异常和完成状态。原始业务响应只保留在 `.local/runs/<Run_ID>/keyword-sif-collector/`。

## Gate

每个成功调用均有完整响应、参数、时间、周期、行数和本机指针；失败竞品有准确原因。任一响应未保存、站点/父子体不明、接口结构冲突或授权不足时回传`blocked/incomplete`。
