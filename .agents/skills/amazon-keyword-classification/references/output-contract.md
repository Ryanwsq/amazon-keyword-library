# Keyword classification output contract

本合同定义 `keyword.library.classify` 的三张派生表、字段、范围和质检门；具体判断边界由项目判定边界文档拥有。

## Input lock

- 锁定第二板块版本、Sheet2/3/4 行数、稳定 `Keyword_ID`、站点、数据周期和分类规则版本。
- 保留第二板块原表，不新增、删除或跨表移动关键词。
- `Sheet5_词频统计`只按版本关联用于流程血缘；本合同不读取词频值或把它作为分类字段。缺失时标记流程不完整并路由到词频 Skill，不在分类步骤重算。
- SKU 事实卡不得输入。

## Sheet2 classification

| 字段组 | 最低字段 |
|---|---|
| 身份 | `Keyword_ID`、关键词、中文翻译、标准化关键词、站点 |
| 来源 | 来源渠道、采集批次、数据周期 |
| 流量 | ABA排名、搜索量、流量层代码、流量层名称、长尾主分组标签、LT分组 |
| 语义 | 词性/词义多标签、类目专属标签版本 |
| 质量 | ABA异常说明、标签复核说明、分类状态、人工复核状态、分类规则版本 |

F1–F5 区间固定。F5 保留全部多标签，并按固定优先级选择一个`长尾主分组标签`；在主标签内按 ABA 升序，每超过20词拆下一 LT组。一个关键词只出现一次，每子组最多20词。没有 ABA 但有规范搜索量时写`ABA未提供`，不伪造层/组。多标签只描述关键词自身含义；无稳定判断时使用`其他/未知`。

## Sheet4 secondary-category classification

最低字段：`Keyword_ID`、关键词、中文翻译、ABA排名、搜索量、流量层代码、流量层名称、长尾主分组标签、LT分组、中心购买对象、二类商品类型、直接替代理由、来源渠道、数据周期、异常说明、人工复核状态和规则版本。

Sheet4 使用与 Sheet2 相同的流量分层，但“二类词”不是 F2“二级流量词”。本表不含词义多标签、竞争或趋势分析，也不修改第二板块的直接替代判断。

## Sheet3 negative-candidate design

最低字段：`Keyword_ID`、关键词、中文翻译、原摘除原因、中心购买对象、否词候选状态、拟否定对象、Sheet2误伤检查、Sheet4误伤检查、判断依据、人工复核状态和规则版本。

在精准/词组否定边界未确认前，不自动输出`精准否定`或`词组否定`为最终结论。若上游已经存在经用户确认的状态，可原样保留并标明来源；其他行保持`需人工确认`。本表不是可直接上传文件。

## Quality gate

1. 三张派生表行数分别等于对应 Sheet2/3/4 的唯一 `Keyword_ID` 数。
2. 三张表主键不跨人口，且每个主键可回查到第二板块原表。
3. 有效 ABA 值落入唯一 F1–F5；F5 每个主键只出现一次、恰有一个主分组标签且每个标签内 LT 子组不超过20行。
4. F2 显示名为“二级流量词”，Sheet4 始终称“二类词”。
5. Sheet2 不含 SKU 匹配、广告资格；Sheet4 不含竞争/趋势；Sheet3 不含未经确认的可执行否词结论。
6. 词频过程 Sheet 缺失、ABA未提供和否词边界均有明确状态，不被空值掩盖；词频不改变任何分类结果，多标签只在 F5主分组时按固定优先级选一个主标签。
