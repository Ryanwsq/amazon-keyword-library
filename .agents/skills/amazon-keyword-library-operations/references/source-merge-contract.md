# Three-source merge and first-board workbook contract

本合同由项目主任务使用，只负责把三个来源副任务的锁定回传做机械合并并装配第一板块十表；它不拥有来源提取、类目清洗或后续业务判断。

## Required handoffs

- SIF：逐竞品原始响应清单、来源记录、查询参数、最近30天口径、数据截止日、抓取时间、接口上限和异常状态。
- Amazon 联想：固定矩阵输入清单、可见建议、环境、执行次数、输入状态和证据指针。
- 卖家精灵：逐种子逐页原始行、全部返回字段、分页状态、实际行数、重复和缺失字段清单。
- 主任务锁定：`Run_ID`、站点、产品事实、自有品牌、类目锚点、SKU事实、代表种子、三个来源版本和允许输出目录。

任一来源缺少稳定记录 ID、版本、状态或原始记录指针时停止合并。Amazon 联想是必选来源；`not_executed`时可以装配问题发现型十表，但第一板块状态必须为不完整。

## Mechanical merge

机械键只允许：去首尾空格、压缩连续空格、英文小写化。不得做单复数归并、词干化、拼写纠正、词序重排、同义词合并、品牌删除、流量过滤或语义删除。

分页边界重复和多来源重复在原始表及来源明细中全部保留；`08_原始关键词总表`每个机械键一行。同来源重复指标冲突时，首次出现值只作展示，全部原值和冲突状态必须保留。

规范 ABA 和规范搜索量优先取卖家精灵；仅存在于 SIF 的关键词回退到 SIF。保留各来源原值、周期、规范来源和回退标记，不平均、不覆盖。SPR 和商品数量只使用卖家精灵，SIF-only 词保持空值。

## Ten-sheet output

| Sheet | Required content |
|---|---|
| `00_执行概览` | Run、站点、产品、周期、三个来源版本与状态、行数、锚点、种子和阻断项 |
| `01_产品事实` | 分区保存类目锚点、自有品牌和 SKU 事实 |
| `02_竞品ASIN` | 获准竞品、父子体、SIF查询状态、周期和返回数 |
| `03_核心大词` | 主锚点、细分品类词、同义表达、代表种子和采用依据 |
| `04_SIF原始数据` | SIF副任务全部获准原始行和字段 |
| `05_搜索框联想` | 联想副任务全部输入状态和可见建议 |
| `06_卖家精灵原始数据` | 卖家精灵副任务全部页行和字段，显式保留SPR、CPC、商品数量、点击集中度 |
| `07_关键词来源明细` | 每个来源事件的一行统一索引 |
| `08_原始关键词总表` | 每个机械键一行，关联全部来源事件和规范字段 |
| `09_异常日志` | 失败、重试、零结果、总数漂移、重复、缺失字段和完成度影响 |

## Quality gate

1. 三个来源回传版本与主任务锁定版本一致。
2. 每条原始来源记录有唯一来源 ID，每个总表关键词至少连接一条来源明细，来源明细可回到原始来源表。
3. 原始来源行数、来源明细行数、机械键数量和重复映射闭合。
4. 没有发生语义删除、语义去重或流量分类。
5. 规范字段来源、回退、周期和逐行缺失状态可识别。
6. 十张 Sheet 和必需列存在；公式错误为零，日期可读，长 ID/来源/周期/说明列可读并换行。
7. 每张 Sheet 已渲染；全部渲染和行数检查由独立质量验证 Skill 再次复核。
8. 任一必选来源未完成、显式适配器错误或联想`not_executed`时，第一板块完成状态必须为`incomplete/blocked`，不得交给清洗作为正式完成输入。
