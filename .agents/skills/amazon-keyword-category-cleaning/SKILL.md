# Amazon Keyword Category Cleaning

## 目标

依据一级品类边界完成三去向清洗，保留原因和可复核闭环，不提前执行 SKU 精准分类。

## 输入

类目锚点卡、自有品牌名及别名、可追溯原始关键词表、规范 ABA/搜索量字段及来源和本轮清洗版本目标。SKU 事实卡只在第一、第二板块内作为来源背景保留，不参与本 Skill 的品类相关性删除，也不传入第三板块。

## 输出

原始表副本、Sheet2 清洗后品类相关关键词库、Sheet3 其他摘除关键词库、Sheet4 二类词词库、附加人工复核标记清单和质检摘要；所有复核项仍有唯一最终去向。

## 可调用能力

- `keyword.library.clean`

## 执行步骤

1. 完整读取 `knowledge/index.md`、`../../../docs/keyword-judgment-boundaries.md` 和 `references/workbook-contract.md`，锁定原始输入、Keyword_ID、输入行数、类目锚点版本和清洗版本。本板块不调用 SIF、Amazon 搜索框或卖家精灵，也不新增关键词。
2. 先执行已确认的流量 OR 门：规范 ABA 排名有效且小于或等于 1,000,000，或规范月搜索量大于 100。规范 ABA 与规范搜索量同时缺失/无效时，或两项均未通过时，进入 Sheet3并写具体原因；缺失情况固定写`缺流量数据`。原始值、来源和周期继续保留。
3. 对通过流量门的完整关键词依次执行六层判断：语义标准化、商品完整性、中心购买对象、与一级品类锚点的关系、单一或多商品、判断充分性。标准化只用于判断，不覆盖原词。
4. 先执行品牌、授权/IP 和 Gift 门：用户声明的自有品牌目标完整商品继续判断并加`自有品牌词`；自有品牌相邻完整商品仍按 Sheet4 条件判断。其他品牌、简称、系列、型号、品牌拼写变体和未声明授权的 IP/角色整词进入 Sheet3，不删除品牌后生成新词。明确 Gift 意图同样进入 Sheet3。
5. 以当前类目的动态目标完整商品对象判断。若中心购买对象仍是类目锚点覆盖的完整商品，或是本类目已经验证为同一完整商品对象的同义表达、有效词序/词形变体，写入 Sheet2；同品类其他细分类型、外观、结构、材质、尺寸、功能、人群或配置不能因目标 SKU 不具备而删除。
6. 英文字母拼写错误若仍可可靠识别为目标完整商品，保留原词进入 Sheet2并加`错字错词`，不增加纠正或建议字段。`错字错词`不包括有效同义词、词序、缩写、词形变体或其他语言。可可靠识别的其他语言目标完整商品进入 Sheet2并加`其他语言`；其他语言相邻完整商品继续按 Sheet4条件判断。
7. 若商品中心已离开一级品类，仅当它是完整商品、与核心品类具有相同主要购买目的、无需额外主要商品即可直接完成任务，并通常进入同一次购买比较时，才写入 Sheet4。缩写的相邻完整商品仍是 Sheet4 候选，不按拼写错误处理。来源只发现候选，不能证明替代关系；Sheet4 允许为零。
8. 配件/互补品/耗材/服务、多商品组合、宽泛或残缺词、泛场景/人群/活动、其他非直接替代完整商品和完全无关词写入 Sheet3。`目标商品 with/without/no 配置`且交付物仍是完整本体时进入 Sheet2；`配件 for 目标商品`或`目标商品 + 配件头部`且交付物是配件时进入 Sheet3。
9. 关键词存在无法由自身消除的歧义时，保守写入 Sheet3并记录具体类型和原因；不得悬空，也不得借助来源背景猜进 Sheet2 或 Sheet4。正式自动化不逐词中断询问。类目等价表达只在当前类目验证版本内有效，不能把单一案例词表复制到其他类目。
10. 检查每条原始词只有一个最终去向、附加标签不替代主类型、重复、空值、公式错误和 `Sheet2 + Sheet3 + Sheet4 = 输入行数`。
11. 渲染各工作表并目视复核。规则在真实验证中修正后重跑当前案例，并输出`旧去向 → 新去向`差异表；未重跑前不得把旧工作簿称为新规则结果。

## 质量标准

- 每条输入词只有一个最终去向，数量闭合。
- Sheet2 以一级品类相关性为准，不把同品类细分类型误删。
- Sheet4 只含直接替代商品，允许为零。
- Sheet3 有可解释的完整词级原因，不依赖单词命中；缺流量、第三方品牌/IP、配件、多商品、宽泛/残缺和无法识别等类型可筛选。
- 拼写错误和其他语言不自动等于摘除；符合目标完整商品门槛时留在 Sheet2且标签正确。
- 任何自动化结果均经过工作表渲染和人工复核。

## 异常处理

缺少类目锚点、自有品牌声明、输入表损坏、行数不闭合或规则冲突时停止整批；保留原始输入，输出问题摘要并请求主任务或用户确认。单个词语义歧义不是让整批悬空或逐词询问的理由，应按已确认规则进入 Sheet3并写明原因；后续真实验证再迭代边界。
