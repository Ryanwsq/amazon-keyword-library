# Amazon Keyword Category Cleaning

## 目标

依据V2.1一级品类边界把第一板块完整词池分为品类相关、其他摘除和二类词，保留事实/锚点和原因，并完成唯一主键人口闭环。

## 输入

锁定的第一板块两Sheet工作簿、Keyword_ID、规范ABA/搜索量及来源、主执行锚点、已确认核心词与等价表达的机械键及证据、完整词覆盖边界、自有品牌、SKU事实、清洗规则版本和输出目录。

## 输出

固定四Sheet工作簿、最小manifest和紧凑状态摘要；不复制完整源表，不生成词性/词义标签。

## 可调用能力

- `keyword.library.clean`

## 执行步骤

1. 读取项目知识、判断边界和`references/workbook-contract.md`；锁定输入名称、哈希、人口、类目锚点和清洗版本。
2. 把SKU事实卡和类目锚点卡写入`Sheet1_事实与类目锚点`，并分开记录主执行锚点、已确认核心词、已确认等价表达和完整词覆盖边界。SKU事实只辅助身份和消歧，不作为删除同品类词的理由。
3. 执行流量OR门：ABA有效且<=1,000,000，或月搜索量>100。两项失败或缺失均进入Sheet3并写准确流量门状态。
4. 对通过流量门的词先执行精确锚点表达门：机械键与已确认核心词或已确认等价表达完全一致时进入Sheet2。核心词不得仅因宽泛、存在其他词典义项或主执行锚点更具体而标记歧义；已确认等价表达不得重新按普通相邻商品判断。
5. 非精确锚点表达必须读取完整短语，按品牌/IP/Gift、完整商品、中心购买对象、一级品类关系、直接替代条件和歧义逐层判定。核心词根或疑似拼写变体只提供候选方向，不得覆盖改变中心商品的决定性修饰语、商品头部或`配件 for 本体`关系。
6. 完整词由已确认核心词/等价表达或其可可靠识别的单复数、所有格、空格、符号噪声、短编辑/相邻换位拼写变体，加上仅描述属性、外观、结构、材质、尺寸、功能、价格、配送、风格、人群、使用场景或随本体配置的词组成，且没有出现另一商品头部时，中心仍是一级品类本体，进入Sheet2。可靠变体必须不构成另一个有效商品词，且词形和完整语境能唯一回指锁定锚点；否则进入完整词歧义判断，不得自动放行。
7. 自有品牌目标完整商品、可靠错字和其他语言目标完整商品不自动摘除。`本体 for 场景`与一个已形成其他商品类别的`场景+核心词`必须按真实中心商品分开判断。配置连接词只提供语法信号，不直接决定去向；并列连接结构可能表达两个主要商品，不能自动当作随本体配置。其他语言按该语言的商品头部、修饰关系和词序判断，不套用英语词序。
8. 第三方品牌/IP、Gift、配件/零件/耗材/服务、多商品、泛词/残缺词、仅场景/人群/活动、非直接替代和无关词进入Sheet3。短语因决定性语义明确改变中心商品时直接按该完整商品判断；只有完整短语仍无法消歧时才进入Sheet3人工复核。
9. 只有完整商品且与一级品类解决相同主要购买任务、无需额外主要商品并通常进入同次购买比较时进入Sheet4。Sheet4允许零行。
10. 核对每个Keyword_ID恰好一个去向，`Sheet2+Sheet3+Sheet4=输入人口`；原词、指标和来源不改写，缺值不填0。规则必须对锁定人口整批执行；另抽查精确核心词、精确等价表达、可靠变体加非变物属性、本体带配置、本体用于场景、并列多商品、其他语言商品头部、其他商品类别和独立配件边界，并反向抽查Sheet2误放、Sheet3误摘及人工复核假阴性。
11. 扫描公式并渲染四Sheet目视复核；问题只写本轮唯一问题文档。

## 质量标准

- 工作簿恰好四Sheet且字段顺序符合合同。
- 第二板块无语义分类标签、SKU匹配或广告资格。
- Sheet2保留同品类词；Sheet3原因可解释；Sheet4只含直接替代且允许零行。
- 通过流量门的精确已确认核心词和等价表达全部进入Sheet2；包含同一词根但中心商品已改变的完整短语不得因此进入Sheet2。
- 可靠词形/错拼/符号变体加非变物属性不会被保守批量送审；不可靠字符串也不会仅靠来源或近似词根进入Sheet2。
- 配置连接、并列连接和其他语言词序均按中心购买对象判断，不以单一连接词或英语词序机械决定。
- 三去向人口、主键、来源和哈希闭合。
- Skill保持draft/planned，旧运行不冒充当前合同P1。

## 异常处理

主执行锚点、已确认核心词/等价表达及其确认依据、类目锚点、自有品牌声明、输入哈希或主键无法锁定，或三去向无法闭合时停止。已确认核心词或等价表达与完整词中心对象发生规则冲突时停止受影响输出并回传主任务，不得自行降级或重定义。其他单词级歧义不停止整批，按Sheet3人工复核规则处理。
