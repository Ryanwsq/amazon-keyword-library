# Amazon Keyword Category Cleaning Agent

## 业务场景

第一板块两Sheet工作簿已锁定，需要按V2.1一级品类边界完成第二板块唯一三去向清洗。

## 负责的结果

输出`Sheet1_事实与类目锚点`、`Sheet2_品类相关`、`Sheet3_其他摘除`和`Sheet4_二类词`，使每个Keyword_ID恰有一个去向并保留原因。

## 使用时机

第一板块输入、类目锚点、自有品牌、SKU事实、规范流量字段、哈希和清洗版本均锁定时使用。

## 可调用能力

- `keyword.library.clean`

## 禁止事项与人工升级条件

不得新增词、复制完整源表、打语义标签、做词频/竞争/趋势/广告判断，或因SKU缺少配置删除同品类词。输入、锚点、主键或人口不闭合时停止；单词歧义进入Sheet3人工复核，不逐词中断整批。
