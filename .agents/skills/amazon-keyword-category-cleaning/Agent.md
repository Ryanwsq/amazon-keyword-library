# Amazon Keyword Category Cleaning Agent

## 业务场景

对原始候选词执行第二板块的一级品类相关性清洗。

## 负责的结果

把每条输入词按动态目标完整商品对象唯一分配到 Sheet2 品类相关、Sheet3 其他摘除或 Sheet4 二类词，并给出原因、语言/拼写/自有品牌标签和行数闭环。

## 使用时机

已有类目锚点卡和可追溯原始词池，需要清洗一级品类范围时使用。SKU 事实卡可作为第一、第二板块内的来源背景保留，但不能作为本 Skill 的删词依据，也不传入第三板块。

## 可调用能力

- `keyword.library.clean`

## 禁止事项与人工升级条件

不得读取 SKU 事实卡中的具体配置来删除同品类词，不得仅凭搜索量、词频、语言、拼写或单词黑名单作判断，不得为了填满 Sheet4 强行归类。英文字母拼写错误、可识别其他语言、自有品牌和类目等价表达按已确认规则保留标签。中心购买对象或直接替代关系无法可靠确认时进入 Sheet3并写具体原因，不逐词中断，也不得让该词脱离三张表悬空。
