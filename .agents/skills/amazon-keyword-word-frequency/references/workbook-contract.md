# Word-frequency workbook contract

## Input lock

锁定第二板块工作簿名称和SHA-256、Sheet2唯一Keyword_ID人口、唯一英文关键词列、词频规则版本、固定英语介词表内容及版本。只读取Sheet2非空英文关键词，不覆盖源文件。

## Tokenization

1. 对统计副本执行Unicode NFKC。
2. 英文字母小写。
3. 空白、标点和连字符作为分隔符。
4. 不合并单复数、同义词、拼写变体、词干、词序或翻译。
5. 不读取ABA、搜索量、来源、SKU事实、竞争或广告字段。

## Preposition filter

使用固定版本英语介词表。介词：

- 不进入单词频次；
- 是相邻双词的硬断点；
- 不得在删除后跨越连接两侧token。

例如`paddle board for adults`只计单词`paddle/board/adults`和双词`paddle board`，不计`for`、`board for`、`for adults`或`board adults`。只过滤介词；冠词、连词和其他停用词保留。

介词清单和版本必须写入manifest，不在不同Run间静默改变。

## Counting and sorting

- 单词：每个非介词token出现一次计一次。
- 双词：在每个连续非介词词段内部生成相邻有序pair。
- 排序：次数降序；同次数标准化词面字符升序。
- 保留所有唯一词面，包括次数1。
- 不建立高/中/低频、权重或占比。

## Fixed output

一个独立过程工作簿，只含一张`词频统计`Sheet。两张表并列：

| 单词词频 | 相邻双词词频 |
|---|---|
| `排名、单词、出现次数` | `排名、相邻双词、出现次数` |

## Manifest

记录输入名称/哈希/人口、分词规则、介词清单/版本、原始token数、过滤介词数、有效单词总数/唯一数、双词总数/唯一数、公式/渲染、输出哈希、状态和唯一问题文档。

## Quality gate

1. 输入行数等于Sheet2非空英文关键词行数。
2. 单词计数和等于全部非介词token数；输出无介词。
3. 双词计数和等于各连续非介词词段`max(词数-1,0)`之和。
4. 双词不含介词且不存在跨介词组合。
5. 输出行数等于唯一单词/双词数，排序稳定且保留次数1。
6. 工作簿只有一张词频Sheet；公式扫描、渲染和目视复核通过。
