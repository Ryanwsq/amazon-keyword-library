# SellerSprite expansion source contract

## Input lock

- `Run_ID`、站点、1–3个主任务确认的代表种子、每页20条和本机忽略目录必须锁定。
- 代表种子从第1页开始；本 Skill 不增加、替换或语义合并种子。

## Raw page record

每行至少保留：来源记录 ID、批次、代表种子、页码、页内序号、站点、采集时间、原始关键词、机械键和全部返回字段。SPR、CPC/PPC竞价、商品数量、点击集中度必须映射到原始字段和值，不重算或覆盖。

## Pagination gate

每个种子必须到明确最后页或空的下一页。总数漂移只有在声明页数稳定、页码连续、无缺页/整页重复/循环且有明确最后页时不阻断；使用实际返回行数闭环。页边界重复原始行全部保留，机械键重复另行列示。

## Handoff

回传主任务：逐页原始响应清单、原始行清单、实际行数、声明总数/页数轨迹、重复组、字段缺失、分页状态和异常。原始业务响应只保留在 `.local/runs/<Run_ID>/keyword-sellersprite-collector/`。

## Stop

报错、限流、结构异常、页数变化、缺页、整页重复、循环、无法确认最后页或关键字段结构性缺失时停止。单行指标空白保留空值，不构成整批结构错误，但必须进入缺失清单。
