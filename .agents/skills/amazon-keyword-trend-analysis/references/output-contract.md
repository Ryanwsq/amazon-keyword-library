# Category monthly-search trend output contract

## Input lock

- 锁定第二板块、分类版本、站点、趋势批次、最早可用月份、最新完整月份和稳定 `Keyword_ID`。
- 只选择 Sheet2 F1–F3；不读取 SKU 事实卡。

## Formal source

整张正式图只使用卖家精灵 `aba_research_trend` 的精确词月度搜索量。每条记录月份必须非空且可解析为`YYYY-MM`。空月份响应无效；卖家精灵不可用或无完整月时标记`not_executed`，不回退 SIF、西柚或其他来源。

## Sheet content

1. 元数据：品类、站点、正式来源、最早月份、最新完整月份、F1–F3关键词数、数据完整性和规则版本。
2. 数据矩阵：第一列`YYYY-MM`，后续每列一个关键词，并能回查 `Keyword_ID`、关键词和流量层。
3. 折线图：横轴年-月、纵轴月度搜索量、每个关键词一条线、图例为关键词。

当前未结束月份不进入。缺失月份留空并记录，不填0、不插值、不前值延续、不用其他来源补齐。

## Excluded outputs

不输出近三月、同比、ABA走势、峰值月、季节性、精确词/长尾结构、品类汇总搜索量线、综合趋势标签、广告资格或投放动作。

## Quality gate

趋势人口等于 Sheet2 F1–F3唯一主键数；F4/F5/Sheet3/Sheet4零混入；月份升序且可解析；每个主键恰好一个矩阵列和一条图表序列；图表引用范围与矩阵一致；来源和缺失状态可追溯。
