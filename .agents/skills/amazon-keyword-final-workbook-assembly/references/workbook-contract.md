# Final workbook contract

本合同只定义最终工作簿的 Sheet 人口、字段和完整性，不拥有关键词业务判断。

## Sheet1 population

`Sheet1_最终关键词决策总表`的唯一人口是第二板块 Sheet2 的唯一 `Keyword_ID`。以下内容不得进入：

- Sheet3 其他摘除关键词和否词库关键词。
- Sheet4 二类词。
- 只存在于来源明细、但未进入 Sheet2 的原始来源事件。

同一 `Keyword_ID` 来自多个竞品、种子或联想入口时，Sheet1 保持一行，`来源渠道`保存去重后的来源集合；逐条来源记录保留在第一板块过程 Sheet。

## Sheet1 fields

| 字段组 | 最低字段 |
|---|---|
| 身份 | `Keyword_ID`、`关键词`、`中文翻译`、`标准化关键词` |
| 来源 | `站点`、`来源渠道`、`采集批次`、`数据周期` |
| 流量 | `ABA排名`、`搜索量` |
| 分类 | `流量层代码`、`流量层名称`、`长尾主分组标签`、`LT分组`、`词性/词义多标签` |
| 竞争 | `Competition_Record_ID`、`综合竞争等级`、`竞争判断摘要`、`竞争数据完整性` |
| 质量 | `数据完整性`、`人工复核状态`、`规则版本` |

详细Top3点击/转化、绝对层、差值结构和过程证据只保留在独立竞争 Sheet；CPC、SPR、商品数量、市场CVR、入场信号和集中度已从当前合同移除。趋势不在 Sheet1 设置行字段。广告资格、广告活动、匹配方式和投放动作也不属于本表当前字段。

F5 不参加竞争：其 `Competition_Record_ID` 留空，`综合竞争等级`写`不适用（F5）`，`竞争数据完整性`写`范围外`。`人工复核状态`是分类与竞争状态的汇总字段；竞争回写不能覆盖分类阶段已经产生的复核状态。

## Required independent outputs

| 逻辑 Sheet | 人口与最低内容 |
|---|---|
| 关键词竞争性分析 | Sheet2 的 F1–F4；竞争记录ID、Top3点击/转化、各自绝对层、差值结构、综合竞争等级、摘要、完整性和复核状态；F5/Sheet3/Sheet4不进入 |
| 二类词流量分类 | Sheet4 关键词；`Keyword_ID`、关键词、中文翻译、ABA、搜索量、F1–F5、LT组、中心购买对象、二类商品类型、直接替代理由、来源和版本；不含竞争性或趋势性分析 |
| 否词库设计 | Sheet3 关键词；原摘除原因、否词候选类型、拟否定对象、误伤检查、判断依据、人工复核状态和版本 |
| 趋势性分析 | Sheet2 的 F1–F3；固定使用卖家精灵月搜索量，一张历年月度折线图和同表数据矩阵，每个关键词一条线，并保留站点、可用年月、缺失和版本 |

## Process-sheet preservation

- 第一板块十张来源采集 Sheet 全部保留。
- 第二板块的清洗源表、Sheet2、Sheet3、Sheet4、词频统计及实际生成的其他判定、复核和质检 Sheet 全部保留。
- 第三板块的流量分类、词性/词义分类、二类词分类、否词库设计、竞争性分析、趋势性分析及实际生成的其他复核和质检 Sheet 全部保留。
- 使用 `B1_`、`B2_`、`B3_` 前缀和 Sheet 清单解决重名；保存原始 Sheet 名称映射。
- 若某一阶段实际存在合同未枚举的过程 Sheet，也必须保留；“最低清单”不是删除许可。

## Quality gate

1. Sheet1 数据行数等于 Sheet2 唯一 `Keyword_ID` 数。
2. Sheet1 与 Sheet3、Sheet4 的 `Keyword_ID` 交集为零。
3. Sheet3、Sheet4 独立输出行数与上游人口闭合。
4. 第一、第二、第三板块实际 Sheet 清单全部映射到最终工作簿。
5. 每个汇总值可通过 `Keyword_ID`、批次、周期和来源渠道回查。
6. Sheet1 的每个 `Competition_Record_ID` 在独立竞争 Sheet 中唯一可回查，且详细竞争列未被复制到 Sheet1。
7. 已完成第二板块清洗的正式批次必须存在可追溯的 `Sheet5_词频统计`；缺失时阻断完整装配并路由回词频 Skill，本装配步骤不重算、不伪造。
8. 趋势 Sheet 只包含 F1–F3，数据矩阵每个 `Keyword_ID` 恰好对应一条图表序列，且折线图引用的月份范围与矩阵一致。
9. 公式错误、重复表名、超长表名、重复主键和空主键均阻断交付。
10. CSV必须先导入临时空工作簿；日期不得显示为序列号，长主键、来源、周期和说明列必须可读并换行；每张 Sheet 都要渲染复核。
11. 趋势 Sheet 使用固定图表区域预览；F1–F3关键词列数、非空月份数和图表序列数必须分别闭合，不能只按 UsedRange 截取矩阵。
12. F5 每个 `Keyword_ID` 只出现一次，保留一个长尾主分组标签且标签内 LT 子组最多20词。
